# FF Shop fidelity checklist

- [ ] Correct font files and weights load; no synthetic bold.
- [ ] Hero composition and line breaks match the reference.
- [ ] Brand wordmark proportions and dominant media crop match.
- [ ] Desktop gutter and major panel boundaries match.
- [ ] Complete section order and footer are present.
- [ ] Repeatable cards keep their distinctive rhythm and metadata.
- [ ] Source asset substitutions are explicitly documented.
- [ ] Menu and visible controls have meaningful states.
- [ ] Phone content remains readable with no body overflow.
- [ ] Keyboard focus and reduced-motion mode are usable.
- [ ] Source demo content is not presented as connected real data.
- [ ] Validation report distinguishes checks performed from assumptions.

Coverage: Public source CSS + official marketplace images; live browser layout unverified.

## Ecommerce checks for the implementing AI

- [ ] Catalog/product source variants preserve the actual category, gallery and purchase layout.
- [ ] Option selection, quantity, selected price, disabled state and errors are coherent.
- [ ] Empty/filled cart and checkout destinations are explicitly configured or marked as demonstrative.
- [ ] Source sample availability and prices are not described as live inventory.
- [ ] Real inventory, taxes, shipping, payment and digital delivery are tested separately when connected.
- [ ] No extra visible storefront feature is added merely because the optional schema mentions it.
