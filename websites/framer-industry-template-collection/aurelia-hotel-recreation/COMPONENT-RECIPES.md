# Aurelia Hotel component recipes

Evidence: Slashdown's official Aurelia Hotel Marketplace listing, four saved official JPGs, root public HTML/CSS and the Tropical Garden Suite public source. Reference JPG 01 was inspected. Public images are visual evidence, not an editable template license. SOURCE DECLARED describes serialized structure and styles; OPTIONAL RECOMMENDATION describes a reconstruction choice. No reservation backend was tested.

## 1. Transparent navigation over a coastal hero

SOURCE DECLARED: Desktop Transparent and Mobile Transparent Closed are named navigation structures. Primary Manrope navigation uses 12px, weight 600, 1.5em line height and .15em tracking; secondary location/phone uses 13px and .15em. The hero has height:100vh and min-height:640px; the tablet rule changes the minimum to 560px. Its photo declares scale(1.2), with independent Noise and Gradient layers. Cormorant Garamond h1 uses 80px/1.1em at 500 with -.04em tracking; tablet is 64px. Official artwork shows the heading left aligned, with the pool/coast remaining recognizable on the right. OPTIONAL RECOMMENDATION: preserve the crop before adjusting type width, layer the contrast gradient independently, and implement a focus-visible menu button. Keep the logo and phone readable on the photograph. Do not copy the surrounding photographed laptop or use a flattened screenshot as hero media.

## 2. Dark booking-request strip with room source records

SOURCE DECLARED: Hero contains Desktop, Tablet and Mobile booking variants, labelled Name, Email, Room Type, Check In, Check Out, Adults and Children. Form labels use Manrope 11px/1.6em at 500 with .2em tracking; Request Booking uses a 13px action style. The desktop strip has forest-green background and inline 12px corners. CMS Room Source items declare separate titles and slugs, including rooms outside the three featured homepage cards. OPTIONAL RECOMMENDATION: use one room collection as the source for cards and request options, but preserve each record's stable ID separately from its title. Build date validation, checkout-after-checkin, party constraints, sending, error and request-received states only when adding real handling. Explain that a request is awaiting confirmation. A public request form is not evidence of confirmed room inventory, payment or a successful booking. Keep inputs labelled after responsive stacking and retain entries after errors.

Body Manrope is 16px/1.6em at 500; small attribution can use Inter 10px at 800. The main About container declares max-width:1180px and padding:160px 24px; tablet declares 120px 24px 64px. Crop atmospheric media rather than stretching it; provide a poster and explicit playback control if video is implemented.

## 4. Room discovery cards and detail continuation

SOURCE DECLARED: Featured Rooms has ID #rooms and links to the archive plus Tropical Garden Suite, Infinity Pool Villa and Sunset Premium Ocean Suite detail routes. Vertical Full and Horizontal card structures retain photography, From price badge, title, area, bed, guest metadata and Explore Room action. Homepage card titles use Cormorant Garamond 28px/1.1em at 700; metadata uses Manrope 14px/1.6em at 500. The inspected Tropical Garden Suite detail source retains 80px hero title, a booking strip, Room, Photos, Amenities Grid, CTA and Other Rooms structures. OPTIONAL RECOMMENDATION: create one coherent card record containing slug, title, media crop, nightly price display, size, bed label and occupancy. Preserve the photo/price relationship and direct title link. Never infer real inventory from a sample price. Detail pages should retain the chosen room in the request journey and identify taxes/currency or confirmation terms when authorized content is available.
