# Lore — component recipes

Basis: official marketplace images and public preview declarations. **SOURCE DECLARED** denotes observed reference facts; **OPTIONAL RECREATION** denotes authored guidance. Media files exist in the public source, but playback and generation interactions were not verified.

## 1. Cinematic hero with protected text

**SOURCE DECLARED.** Hero declares an MP4 asset and poster under its visual region. The official reference places the proposition at left over a teal underwater scene, with an announcement and two pill actions. DM Sans title styling is 54/64.8px, weight 500, with negative tracking. A nested phrase changes to muted gray.

**OPTIONAL RECREATION.** Use a standalone media element, a poster and an intentional dark gradient that protects the whole text region across crops. Offer playback controls when motion conveys product output; retain a useful poster when autoplay is blocked. The announcement links to a real release note. Give both actions visible focus states. 

## 2. Numbered creation sequence

**SOURCE DECLARED.** Three dark cards illustrate writing, generation progress and sharing. Their screenshots contain model/duration chips, output frames, a progress label and export destinations. DM Sans indices and card headings declare 32px, weight 400, at 1.2em line height.

**OPTIONAL RECREATION.**  Separate illustrative progress from a live status component. If visitors can run a sample preview, announce loading and completion without moving focus. Label format options as examples unless functional export exists. Stack the cards in process order on phones and keep their explanations outside the tiny simulated interface.

## 3. Output carousel with prompt disclosure

**SOURCE DECLARED.** Showcase contains vertical MP4/poster cards, named prompt-card variants, model labels, prompt headings and arrow artwork. The reference displays neighboring outputs rather than a single full-width slide.

**OPTIONAL RECREATION.** Use a scrollable row with explicit previous/next controls and a stable active position. Reveal prompt detail through a button that works by keyboard and touch; do not make hover the only route. Distinguish selected, playing, paused, loading and unavailable media states. Retain a readable model label without suggesting that an unintegrated model is available in the product.

## 4. Asymmetric capability bento

**SOURCE DECLARED.** Features combines compact model and output-quality counters with wider style, export and model-switching tiles. Individual images have dark overlays so white typography remains dominant. The metric role declares DM Sans 60/72px at weight 500.

**OPTIONAL RECREATION.** Define semantic grid areas and map each tile to a supported benefit. Keep the larger tile visually larger after content changes, then collapse to a sensible reading sequence on phones. Use a fixed text-protection layer instead of assuming every future image is dark enough. Replace counts, resolution and unlimited-usage assertions with real limits.
