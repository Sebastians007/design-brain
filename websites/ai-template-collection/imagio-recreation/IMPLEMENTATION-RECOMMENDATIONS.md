# Recommended reconstruction workflow

1. Read the specification, CSS declaration map and recipes before choosing components.
2. Identify the active variant at the desired width; preserve font variation, line height, image focal crop and layout constraints.
3. Build the static home page first. Prioritize silhouette, hero wraps, major whitespace and section order.
4. Add accessible menus, accordions, tabs and carousels only where the reference calls for them.
5. Render at desktop, tablet and phone sizes. Use side-by-side screenshots to adjust geometry; source declarations alone do not prove the rendered result.
6. Document substitutions, unavailable media and unobserved states. Check reduced motion, keyboard access and local asset loading.

Recommendations: reserve image aspect ratios to avoid layout shifts; ensure fonts load before fitted wordmarks are measured; provide visible focus; keep all reveal text readable without animation; distinguish illustrative interface data from working integrations. Do not add extra visible website sections merely because this implementation guide mentions them.
