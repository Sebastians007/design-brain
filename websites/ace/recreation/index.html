FAQ

Everything
You Need to Know.

A few answers about the reference, the recreation, and what you can explore here.

What exactly is Ace?

The source presents Ace as a platform for building and coordinating AI agents. This site is an independently built recreation of its visual design, with a small local demonstration.

Do I need technical skills to use the demo?

No. Open the demo, choose an example or write a goal, and select “Preview workflow.” Everything happens in your browser.

How is this different from a live agent platform?

This recreation demonstrates the landing page and its interactions. Its workflow preview is a deterministic simulation; it does not call an AI service, run research, or perform external work.

What tools and apps does the demo integrate with?

No accounts are connected. The visual integration theme follows the reference, while the preview keeps all inputs local to this page.

What happens to the goal I enter?

Your goal is used only to render the demonstration in this tab. The application does not send it to a server or save it after you leave.

Can I try it before choosing a plan?

Yes. All plan buttons open the same free local preview. The plan label demonstrates selection behavior and does not start a subscription.

How quickly can I explore a workflow?

Immediately. Choose an example goal and preview the three steps. You can reset the preview and try a different goal at any time.
