# Ace

A quiet AI-agent landing page: black ground, cyan signals, Bespoke Serif headings, Inter body text, sparse tile animations and generous spacing.

**Working recreation:** https://ace-design-brain.smartbuzz.chatgpt.site (private deployment).

**Source:** [Ace preview](https://ace.framer.media/) · inspected October 8, 2026.

Open `recreation/index.html` directly or run `python3 -m http.server 8000 --directory recreation`. There is no build step and no runtime package dependency. All application assets are local.

The recreation preserves the layout and design language while using original substitute copy, illustrative reviews, and a local workflow simulation. CTA buttons do not create real agents or subscriptions. Desktop source evidence is included; implementation browser comparison and source phone screenshots are not.
