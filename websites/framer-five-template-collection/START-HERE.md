# Five Framer recreation reference packages

Atlas Studio, Platform, Agentic, Arpeggio, and Rescale. Four were inspected in live previews; Rescale uses its public source CSS and official marketplace imagery because browser rendering could not be verified. The collection extends the Soren package with five distinct design references in the same four-file format.

## Start with one template

1. Open `collection-showcase.html` to compare the five references.
2. Choose a folder and open its `frame-showcase.html`. Each guide embeds its visual references and fonts for standalone viewing.
3. Give your coding AI the selected template's entire folder or its individual ZIP, and paste that folder's `AI-HANDOFF.md` instruction.
4. Ask the AI to use `FRAME.md` as the specification and the screenshots as visual acceptance references.
5. Check the resulting implementation with `FIDELITY-CHECKLIST.md` before polishing motion or adding new content.

Do not hand an AI all five folders without identifying which design to recreate. Combining their palettes, typefaces, section order, or motion would reduce fidelity.

## The four core files in each folder

| File | What it supplies |
|---|---|
| `FRAME.md` | Detailed recreation rules: visual hierarchy, typography, palette, layout, section anatomy, and evidence limits |
| `frame-showcase.html` | A visual reference guide with screenshots, tokens, specimens, and implementation notes |
| `reference-frames.jpg` | Twelve labeled source crops; live previews for four templates, official imagery for Rescale |
| `caption-skin.html` | An optional video-caption adaptation retaining the original supplied engine contract |

The caption file is a video companion. It is not a native feature observed on these websites, and remains empty until the caption producer injects the groups, duration, dimensions, and brand tokens. Keep its bundled assets alongside it.

## Additions for reliable AI reconstruction

Each package adds a ready-to-paste handoff instruction, machine-readable design tokens, asset provenance, fonts/media, source screenshots, responsive/motion notes, measurement evidence, and a fidelity checklist. Read the evidence labels: rendered observations, public-CSS declarations, inference, and recommendations serve different purposes. Exact desktop landmarks should not be turned into absolute-positioned page coordinates.

This is an independently authored reference collection, not the editable Framer projects. Detailed inspection coverage and unverified behaviors are documented per template. Use the supplied provenance when selecting assets for production.
