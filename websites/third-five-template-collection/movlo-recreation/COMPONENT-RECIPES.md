# Movlo component recipes

These independently authored recipes describe reusable construction patterns from the supplied public source and official reference imagery. Typography values are source declarations; dimensions below are implementation recommendations unless explicitly identified as declared. Preview: https://movlo.framer.website/. Creator: Ruslan Siiz.

## 1. Scenic teamwork hero

Build a full-width stage around a panoramic painted landscape, preserving sky above the headline and mountain silhouettes beside the dashboard. Place a translucent navigation capsule near the top, followed by a tiny icon label, centered General Sans headline, and capsule action. The desktop hero headline declares 60px, weight 600, with a 60px line. Below, align three compact capability cards; use a solid charcoal active card and a lime progress hairline. Anchor a broad dark dashboard near the lower edge. Expose scenery, headline, capability data, active index, and demonstration asset as props. Mobile should retain atmosphere while presenting fewer dashboard details. Promotional monitor framing stays outside this component.

## 2. Capsule action with arrow well

Use one elongated charcoal pill containing a text label and a separate lime oval button at its trailing edge. The arrow remains black and centered; the label stays white. Navigation declares a translucent background with an 8px backdrop blur and fully rounded corners. Hero action text declares General Sans 16px, weight 500, and a 16px line. Support small navigation and larger conversion variants through padding rather than changing the motif. Make the entire control one accessible link with a clear label. Keep the arrow decorative and expose a visible focus state. Recommend a subtle hover brightness change; exact source transition timing is unverified.

## 3. Alternating product feature stage

Create a large rounded stage with a vivid ambient backing and an inset dark interface scene. Divide it into a description column and product illustration, reversing their positions between neighboring sections. Each description contains a lime line icon, concise title, short body, result figure, and repeated capsule CTA. Source order is project management, calendar integration, then AI assistance. Keep illustrative calendars, timeline marks, and prompt chips specific to their feature. Store orientation, scenic background, UI asset, title, metric, and action as inputs. On narrow screens, stack description before demonstration. Preserve internal hierarchy and readable UI labels instead of uniformly shrinking the whole stage.

## 4. Sentence with embedded interface objects

Render the central manifesto as a spacious centered paragraph whose line flow accommodates inline visual objects. Replace selected conceptual words with a team-avatar capsule, lime task toggle, compact tools icon pill, and tiny stacked note cards. These objects should align optically with the text baseline while retaining their individual silhouettes. Use responsive inline wrappers so the sentence remains grammatical when line breaks change. Keep the surrounding panel nearly black, letting white text and lime accents carry the hierarchy. Treat objects as supporting illustrations unless a real interaction exists. Expose sentence segments and accessible equivalents; recommend static switch styling when behavior is unavailable.

## 5. Navy customer-proof mosaic

Assemble a dark navy mosaic using three reusable tile types: statistic, portrait, and quotation. Mix tall image tiles, compact result tiles, and wider quote panels rather than enforcing equal rectangles. Maintain consistent rounded corners and narrow gutters. Statistics use large white numerals with muted supporting text; portrait tiles use warm abstract imagery and bottom-aligned author metadata; quote tiles carry a partner mark, statement, avatar, and role. Keep customer records and layout spans configurable. Source desktop structure explicitly nests three-up and two-up groups. Collapse those groups into a deliberate mobile sequence. Keep proof claims attached to their original records and avoid inventing animated counters or carousel timing.
