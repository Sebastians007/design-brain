# Message — five component recipes

Basis: official Message marketplace artwork and public preview HTML/CSS. These are original recreation instructions. Source declarations establish structure and typography; spacing suggestions and interaction choices below are recommendations, not measured browser behavior.

## 1. Landscape-led companion hero

Create a full-width stage with the landscape as a separate background image beneath real heading, paragraph, navigation and action elements. Preserve the misty teal opening, dark foreground and restrained white composition seen in the official artwork. The source declares a 100vh hero and a regular Host Grotesk heading at 56px with a one-em line height and negative tracking. Keep the title compact enough that the landscape remains part of the story. Use DM Sans for the supporting sentence and a white pill action. Add a subtle grain layer with pointer events disabled. Recommendation: protect text contrast with a localized overlay and make the scroll cue supplementary.

## 2. Three illustrated capabilities

Use the first Features section as a row of three image-led capability cards, each followed by a short title and concise explanation. The reference combines landscape fragments with small dark interface windows, showing automation, writing and helpful guidance without introducing a full dashboard. Build those images as authored product scenarios rather than unrelated stock photography. Maintain consistent image ratios and align text baselines while allowing the imagery to carry different compositions. Source sections use a maximum-width declaration of 1128px and generous internal padding. Recommendation: on phones, stack the images and copy in reading order; replace dense illustration text with a legible HTML caption below.

## 3. Selectable use-case stage

Treat the second Features section as one shared content stage controlled by four use-case labels. Source includes Active and Default cards plus a mobile slideshow counterpart. Represent the selected label with a thin rule or quiet tonal change instead of a saturated badge. Give each choice its own short proposition, image and start action while preserving the same stage dimensions to reduce disruptive jumps. Recommendation: use real buttons with an announced selected state, visible keyboard focus and a descriptive panel relationship. Show previous/next controls when appropriate. A static first-panel fallback must still explain the product if scripts or motion are unavailable.

## 4. Quiet proof and plan cards

Pair concise proof with a disciplined commercial section. The testimonial structure contains four attributed entries, counters and arrow elements; pricing contains three plan cards and monthly/yearly controls across responsive variants. Keep both modules visually quiet so they belong to the dark reading system. Use thin borders, regular display titles, compact DM Sans labels and sufficient vertical separation between price and feature lists. Recommendation: implement the billing selector as an explicit state with a complete pricing source, rather than inferring annual amounts from template sample figures. Replace testimonial text with authorized evidence and preserve names/roles as distinct fields. Keep CTA focus states clearly visible.

## 5. FAQ and closing invitation

Build six FAQ rows with a question button, disclosure indicator and answer region, followed by a separate landscape closing stage and footer. The source includes Closed FAQ structures and initially transparent FAQ/FinalCTA elements; those declarations do not establish a working reveal animation. Recommendation: present all critical information without waiting for scroll effects. Let the FAQ answer practical assistant questions about supported inputs, limits, data handling and support. The closing stage should contain one clear action and a short sentence rather than another capability grid. Preserve the footer's brand, navigation, social destinations and creator attribution structure, while auditing its unrelated sample description before any product adaptation.
