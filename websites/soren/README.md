# Soren: editorial portfolio

Reference package for the **Soren** Framer template by Bryn Taylor. Source: https://soren-template.framer.website/ (inspected 2026-10-06).

Start with `AI-HANDOFF.md`, then `FRAME.md`. Open `frame-showcase.html` to preview.

## Notes
- **Desktop only.** Measurements and screenshots are desktop (1363x936). Breakpoint values are read from the public CSS; phone/tablet appearance and exact motion were not verified.
- **Assets not included.** The original package bundled the template's fonts (Halibut Variable, Switzer, Chivo Mono), project images and GSAP. They are left out of this public repo. `assets-manifest.json` lists the sources; get the fonts under their own licenses or substitute. `frame-showcase.html` still embeds fonts and images for preview.
- **Video caption skin omitted.** References to `caption-skin.html` in the docs can be ignored for website work.
- This is a visual specification, not the editable Framer template or a pixel-perfect claim.
