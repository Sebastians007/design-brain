## How to use it

1. **Browse** the looks below.
2. **Open** a folder and double-click `frame-showcase.html` to see the palette, fonts and sample frames in your browser.
3. **Copy** that folder's `FRAME.md` into your project as `frame.md`.

That's it.

## What's in each folder

| File | What it is |
|---|---|
| `FRAME.md` | The look: colors, fonts, components, rules |
| `frame-showcase.html` | Visual preview. Open in a browser |
| `caption-skin.html` | Matching caption style |
| `reference-frames.jpg` | 12 real frames from the source video |
