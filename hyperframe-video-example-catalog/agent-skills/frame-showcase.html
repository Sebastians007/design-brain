05

Frame Rules

One Accent · Flat Ground

Do

  • Land each word on the spoken beat; hard-cut or quick fade on the same yellow.
  • Dim non-matched siblings in a tree to about 35% opacity.
  • Keep the yellow ground flat, with only one cyan word per line.
  • Use mono for system text only; cards get soft shadows.

Don't

  • Don't add a second accent colour to keywords.
  • Don't use dark grounds except for cards.
  • Don't bold the mono.
  • Don't use a dark theme or multi-colour keywords.
