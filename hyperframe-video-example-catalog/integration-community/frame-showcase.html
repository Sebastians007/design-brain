05

Frame Rules

Energetic Then Calm

Do

  • Give each statement its own flat ground and keep text left-aligned and oversized.
  • Set the key word about twice as large, in the accent colour.
  • Keep the tutorial half quiet: slow cursor, word-synced captions.
  • Frame the close with four thin white corner brackets.
  • Use gradient text only for the URL.

Don't

  • Don't reuse a card palette twice in a row.
  • Don't centre statement text except on the end card.
  • Don't use the same ground and font on every card.
  • Don't add shadows to the cards.
  • Don't use real brand marks.
