05

Frame Rules

Black Stage · One Green

Do

  • Time hard cuts to the voice; flip black to white to separate voice and UI cards.
  • Rotate every sticker so it follows the curve.
  • Keep green as the only accent; code syntax colours stay inside code panels.
  • Show real custom beziers on screen when talking about eases.
  • Set lower captions in bold white, bottom centre.

Don't

  • Don't use a second accent colour outside code syntax.
  • Don't blur anything.
  • Don't leave a sticker un-rotated on the curve.
  • Don't use soft pastel UI.
